# Security Policy

## Reporting a vulnerability

API key、OAuth、session、認可回避、SSRF、secret 漏えいに関する問題は、public GitHub Issue で報告しないでください。

GitHub repository の **Security** タブから private security advisory を作成して報告してください。可能であれば、再現手順、影響範囲、修正案を添えてください。secret や実在ユーザーの access token は報告本文に含めないでください。

修正の調整、公開時期、credit の扱いは private advisory 内で行います。
